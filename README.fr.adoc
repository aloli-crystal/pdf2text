= aloli-crystal/pdf2text — extracteur de texte PDF pur Crystal
:toc: left
:toc-title: Sommaire
:source-highlighter: rouge

Bibliothèque et CLI Crystal pour lire un PDF, parcourir son arbre
d'objets et extraire le texte avec ses positions (page, police,
boîte englobante). Aucune dépendance externe — uniquement la
stdlib Crystal.

== État courant (v0.3.0)

* Lecture du header PDF + indexation bytes-safe des objets
* Walking du `/Catalog` → `/Pages` tree + dimensions `/MediaBox`
* Décompression FlateDecode + auto-détection par signature zlib
* Parsing du ToUnicode CMap (`beginbfchar` + `beginbfrange`)
* Décodage des strings HEX `<002500480055>` en Unicode via CID map
* Bbox précises via parsing `/W` (per-CID widths) + `/DW`

== Comparatif vs pdftotext (poppler)

Sur 6 PDFs aloli-crystal/pdf variés, pdf2text extrait
**systématiquement plus de mots** que pdftotext :

[%autowidth]
|===
| PDF | pdf2text | pdftotext | Δ
| `beryl` | 2681 | 2587 | +94
| `crystal-asciidoctor-pdf` | 5193 | 4997 | +196
| `crystal-combine-pdf` | 5756 | 5296 | +460
| `toml` | 3085 | 2899 | +186
| `noto-cjk` | 1573 | 1484 | +89
| `deploy` | 3803 | 3579 | +224
|===

Validation bbox sur « Beryl » du README beryl : pdf2text et
pdftotext renvoient x=36.0 w=82.0 — **identique au 1/100ᵉ près**.

== Installation

[source,yaml]
----
dependencies:
  pdf2text:
    github: aloli-crystal/pdf2text
    version: "~> 0.3"
----

== Utilisation programmatique

[source,crystal]
----
require "pdf2text"

extract = Pdf2Text::Extractor.extract("doc.pdf")
puts "Pages : #{extract.pages.size}"
extract.pages.each do |page|
  page.words.each do |w|
    puts "  #{w.text} @ (#{w.bbox.x_min}, #{w.bbox.y_min}) " \
         "size=#{w.font_size} font=#{w.font_name}"
  end
end
----

== Utilisation CLI

[source,bash]
----
pdf2text doc.pdf              # résumé textuel
pdf2text doc.pdf --json       # JSON structuré
pdf2text doc.pdf --pages      # nombre de pages
pdf2text --version
pdf2text help
----

== Pourquoi ne PAS dépendre de pdftotext ?

`pdftotext` (poppler-utils) marche très bien mais demande une
installation système non triviale (Docker minimal, CI Alpine,
sandbox). `pdf2text` reste utilisable __en complément__ — il
vise à fournir une alternative __native Crystal__ pour les
projets qui veulent éviter cette dépendance externe.
